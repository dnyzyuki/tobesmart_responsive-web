투비스마트 스터디큐브 솔루션

스터디카페와 관리형독서실의 무인 운영을 극대화할 수 있도록
안정적이고 직관적인 결제 및 예약 시스템이 결합된 키오스크로,
좌석 선택/ 시간 연장/ 입퇴실 관리/ 빈틈없는 매출 관리 기능을 제공합니다.

스탠드 키오스크

공통기능

  • 카드 전용 결제 (IC카드, 삼성페이, 제로페이, 간편결제, 지역화폐)
  • 좌석구매, 예약 및 연장 (자유석, 고정석, 스터디룸, 사물함)
  • 휴대폰 번호, QR 입퇴실 가능
  • 실시간 좌석 및 이용권 현황
  • 자유로운 좌석 이동
  • 운영 시간 및 휴무일 안내
  • 블랙 고객 이용 및 출입 제한
  • 알림톡 자동 전송
  • 과세/면세 결제로 스터디카페, 독서실 모두 지원

사양

  • 배리어프리 키오스크 21.5' / 24' / 32'
  • 모델명 : BSK-24F-Stand
  • CPU : Intel i5 Processor
  • Memory : 256G / 128GB
  • RAM : 8GB
  • Monitor : 32인치 / 24인치
  • Size (32') : 524(W) x 1902.5(H) x 543(D)
  • Size (24') : 450(W) x 1626.3(H) x 450(D)
  • Weight : 20kg / 17kg
  • 거치대 : 데스크형 거치대 / 스탠드형 키오스크 거치대
  • 배리어프리 : 멀티패널 마이크, 촉각 키패드, 점자 스티커, QR리더기

출입통제 시스템

QR, 지문, 얼굴 인증 이외에 발열체크 등을 단말기로 연동하여
방역정보 및 마스크 착용 여부를 꼼꼼히 체크합니다.

무인 사물함

키오스크, 모바일웹과 연계되어 사물함을 판매하며 고객에게 발급된
QR을 통해 간편하게 결제/개폐하여 편의를 제공합니다.
사용자가 매우 편리하게 사물함을 관리/사용할 수 있는 최신 사물함입니다.

* 사물함 개별 크기: 350(H) x 350(W) x 400(D) mm

외출/퇴실기

내부에서 외부로 나갈 때 사용하는 전용 외출/퇴실기입니다.
퇴실 시 등록된 보호자에게 알림톡이 전송되며, IOT 시스템과 바로 연동되어
매장 자동 제어 및 운영의 완벽한 편리성과 수익극대화 환경을 제공합니다.

스터디큐브 IOT (조명 및 전원제어)

좌석별로 각인된 사용 상태에 연동되어 조명 및 전원 소켓을 매장이 알아서
자동 제어해주는 스마트 IOT 제어 기능을 제공합니다.

스터디큐브 출입제어

매장에 비치된 인터넷 전용선이 끊어져도 O.K.
키오스크 기기의 전원이 예기치 않게 종료되어도 정상 작동하는
최신 독립적 개폐 통제 시스템을 지원합니다.
